# FotoFold

Fold a paper strip, photograph it, color the parts, and hear the fraction.

Open it: https://fotofold.github.io

Class report for teachers: https://fotofold.github.io/report.html

- Works in the phone's browser. Nothing to install, no sign-in.
- No names: students use a class code and a number. Photos are never kept.
- On its own, nothing is sent anywhere: the student saves or copies their record, and the teacher reads the records in the class report, in their own browser.
- In a live class (live.html), the student's number and answers go to the teacher's screen through a small relay, which deletes the class 12 hours after it starts.
