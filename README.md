# FotoFold

Fold a paper strip, photograph it, color the parts, and hear the fraction.

Open it: https://fotofold.github.io

- Works in the phone's browser. Nothing to install, no sign-in.
- Collects nothing: students use a class code and a number, not names. Photos are never kept. Nothing is sent anywhere; the student copies or saves their own record.
