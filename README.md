# FotoFold

Fold a paper strip, photograph it, color the parts, and hear the fraction.

- FotoFold: https://fotofold.github.io
- FotoSet, fractions with coins (new, for trying out): https://fotofold.github.io/fotoset.html
- Live class for teachers: https://fotofold.github.io/live.html
- Class Report for teachers: https://fotofold.github.io/report.html

Works in a phone's or computer's browser. Nothing to install, no sign-in.

- No names: students use a class code and a number. Photos are never kept.
- On its own, nothing is sent anywhere: the student saves or copies their record, and the teacher reads records in the Class Report, in their own browser.
- In a live class, the student's number and answers go to the teacher's screen through a small relay, which deletes the class a week after it starts.
