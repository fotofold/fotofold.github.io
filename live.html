Start a live class.

You get a code and a QR code for the board. Students scan it, type their number, and work through a set on their own phones. Their answers show up here as they go: numbers only, no names.

Students show up here as they join, by number. The relay deletes the class a week after it starts. You can save it and erase it sooner.

Students: scan this with the camera, or open the FotoFold site and type the code.
Getting back to this class

On this computer, open fotofold.github.io/live.html again: the class comes back by itself. From another computer, use this return link. Anyone with it can see the class, so keep it to yourself.
